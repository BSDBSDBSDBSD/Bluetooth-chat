# NearChat

אפליקציית צ'אט מקומית ל־Android 13 ומעלה. עובדת **בלי שרת ובלי אינטרנט**: הטלפונים מתחברים ישירות זה לזה דרך **Bluetooth** או **Wi‑Fi Direct**.

## מה יש באפליקציה

- **חיבור ישיר בין מכשירים**
  - Bluetooth קלאסי (RFCOMM). לא צריך צימוד מראש, כי ההצפנה של האפליקציה עצמה מגנה על ההודעות.
  - Wi‑Fi Direct: חיבור Wi‑Fi ישיר בין שני טלפונים, בלי ראוטר ובלי אינטרנט. טלפון אחד משמש "מארח" והאחרים מתחברים אליו.
  - מצב **אוטומטי** מפעיל את שתי הדרכים ביחד.
- **רשת Mesh קטנה**: כל טלפון מעביר הלאה הודעות שלא מיועדות לו. כך יכולים לדבר גם שלושה טלפונים ויותר שלא כולם מחוברים ישירות זה לזה, ואפילו טלפון ב־Bluetooth עם טלפון ב־Wi‑Fi Direct דרך טלפון שלישי.
- **שיחות פרטיות וקבוצות**.
- **סוגי הודעות**: טקסט, תמונות (מוקטנות אוטומטית) והודעות קוליות (AAC).
- **עריכה ומחיקה**: עריכת הודעה, "מחק לכולם" ו"מחק אצלי".
- **סטטוס הודעה**: 🕓 ממתין · ✓ נשלח · ✓✓ התקבל.
- **תור הודעות**: הודעה שנכתבה כשהצד השני לא מחובר תישלח אוטומטית כשהוא יתחבר.
- **חיבור מחדש**: האפליקציה מתחברת מחדש אוטומטית ב־Bluetooth למכשירים שכבר דיברת איתם.
- **שירות רקע**: ממשיך לקבל הודעות גם כשהאפליקציה סגורה, ומציג התראות.

## אבטחה

| מה | איך |
|---|---|
| זהות | זוג מפתחות ECDH P‑256 לכל התקנה |
| שיחה פרטית | ECDH, ואחריו HKDF‑SHA256 ו־AES‑256‑GCM, מקצה לקצה. טלפון שמעביר את ההודעה בדרך לא יכול לקרוא אותה, והכותרת קשורה להצפנה (AAD) כך שאי אפשר לשנות את הנמען |
| קבוצה | מפתח AES‑256 אקראי שנשלח לכל משתתף בתוך הזמנה מוצפנת פרטית |
| אחסון במכשיר | כל ההודעות, התמונות וההקלטות מוצפנות ב־AES‑GCM, עם מפתח שעטוף במפתח של Android Keystore |
| אימות | "מספר בטיחות" במסך פרטי השיחה להשוואה פנים מול פנים, ואזהרה אם מפתח של איש קשר משתנה |

מגבלות ידועות: בתוך קבוצה, חבר קבוצה יכול תיאורטית להתחזות לחבר אחר (אין חתימה נפרדת לכל שולח). חברי קבוצה נקבעים ביצירה ואי אפשר להוסיף חברים אחר כך.

## בניית APK דרך GitHub Actions

1. מעלים את כל התיקייה ל־repo (כולל `.github` ו־`gradle`).
2. כל push ל־`main` מריץ את ה־workflow **Build NearChat APK**.
3. אם הבנייה מצליחה:
   - ה־APK מתפרסם ב־**Releases → latest** (קובץ `NearChat.apk`), ואפשר להוריד אותו ישירות בטלפון.
   - הוא נשמר גם כ־Artifact של הריצה.
4. בכל מקרה, הלוג נשמר בענף `build-output` (`build.log` ו־`errors.txt`).

## בנייה מקומית

דרוש JDK 17 ו־Android SDK 35. אפשר לפתוח את הפרויקט ב־Android Studio, או להריץ:

```
./gradlew :app:assembleDebug
```

הקובץ נוצר ב־`app/build/outputs/apk/debug/app-debug.apk`.

## איך בודקים עם שני טלפונים

1. מתקינים את ה־APK בשני הטלפונים. צריך לאפשר "התקנה ממקורות לא ידועים".
2. בפתיחה הראשונה מאשרים את כל ההרשאות: מכשירים בקרבת מקום, Bluetooth והתראות.
3. **Bluetooth**
   - בטלפון א': חיבור ← **הפוך לגלוי**.
   - בטלפון ב': חיבור ← **חפש מכשירים** ← **התחבר** ליד שם טלפון א'.
4. **Wi‑Fi Direct**
   - בשני הטלפונים: Wi‑Fi דלוק (לא צריך להתחבר לשום רשת).
   - בשני הטלפונים לוחצים **חפש מכשירים**.
   - בטלפון אחד לוחצים **התחבר** ליד השני, ומאשרים את הבקשה בטלפון השני אם מופיעה.
   - לשלושה טלפונים ויותר: אחד לוחץ **צור רשת (מארח)**, והשאר מתחברים אליו.
5. אחרי כמה שניות השני מופיע ב"שיחה פרטית" כ**זמין**, ואפשר להתחיל לכתוב.
