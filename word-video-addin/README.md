# נגן וידאו ל-Word 2019

תוסף ל-Word 2019 (וגם ל-2016 ול-365 על Windows) שמנגן סרטון מהמחשב **בתוך המסמך עצמו**, בלי אינטרנט.

אחרי ההתקנה מופיעה ב-Word לשונית חדשה בשם **וידאו**, ליד הלשונית "הוספה".

| כפתור | מה הוא עושה |
|---|---|
| הוסף וידאו | בוחרים קובץ, ונגן עם כפתורי הפעלה, עצירה ועוצמת שמע נכנס למקום הסמן |
| החלף סרטון | מחליף את הסרטון בנגן שבשורה של הסמן |
| קטן / בינוני / רוחב מלא | משנה את גודל הנגן שבשורה של הסמן |
| רענן נגנים | מחבר מחדש את כל הנגנים במסמך לקבצים |
| עזרה | הסבר קצר |

סוגי קבצים: MP4, WMV, AVI, MOV, MPG, MKV, 3GP, וגם קובצי שמע (MP3, WAV, WMA, M4A).

## התקנה

### הדרך הכי פשוטה: המסמך המתקין

פותחים את `WordVideo-Install.docm`, מאפשרים עריכה ומאקרו אם מופיע פס אזהרה צהוב, ולוחצים למעלה בלשונית **"התקנת וידאו"** על **"התקן את התוסף"**. זהו. מופיעה הלשונית **וידאו** והתוסף ייטען בכל פתיחה של Word. (הסרה: באותה לשונית, "הסר".)

### או: התקנה ידנית של קובץ ה-dotm


הקובץ `WordVideo.dotm` הוא תוסף רגיל של Word. אין צורך להריץ שום תוכנה.

**לפני ההתקנה:** לחץ על הקובץ בלחצן הימני ← **מאפיינים**. אם מופיעה בתחתית האפשרות **"בטל חסימה"**, סמן אותה ולחץ **אישור**. Windows חוסם קבצים שהורדו מהאינטרנט, ובלי זה Word לא יפעיל את התוסף.

**דרך א' (מומלצת): התוסף ייטען בכל פתיחה של Word**
1. סגור את Word.
2. פתח את סייר הקבצים, הקלד בשורת הכתובת `%appdata%\Microsoft\Word\STARTUP` ולחץ Enter.
3. העתק את `WordVideo.dotm` לתיקייה הזו.
4. פתח את Word. ליד הלשונית "הוספה" אמורה להופיע הלשונית **וידאו**.

**דרך ב': דרך חלון התוספים של Word**
1. ב-Word: **קובץ ← אפשרויות ← תוספות**.
2. בתחתית, ב"נהל", בחר **תבניות** ולחץ **מעבר**.
3. לחץ **הוסף**, בחר את `WordVideo.dotm` וודא שהוא מסומן.
4. אם הלשונית מופיעה אבל הכפתורים לא עושים כלום, Word חוסם את התוסף כי הוא לא נמצא במיקום מהימן. במקרה כזה השתמש בדרך א'.

**הסרה:** מוחקים את `WordVideo.dotm` מתיקיית STARTUP, או מבטלים את הסימון שלו בחלון התבניות והתוספות.

## איך זה עובד

- כשמוסיפים סרטון, התוסף מעתיק אותו לתיקייה בשם `<שם המסמך>_media` שנמצאת ליד המסמך. לכן צריך לשמור את המסמך לפני שמוסיפים סרטון.
- הנגן הוא רכיב Windows Media Player בתוך הדף.
- בכל פתיחה של מסמך, התוסף מחבר את הנגנים לקבצים בתיקייה שליד המסמך. לכן אפשר להעביר את המסמך למקום אחר, כל עוד מעבירים איתו גם את התיקייה.

**העברה למחשב אחר:** מעתיקים את המסמך **יחד עם** תיקיית ה-`_media`, ומתקינים את התוסף גם במחשב השני.

## בעיות נפוצות

- **פס צהוב "אזהרת אבטחה" כשפותחים את המסמך:** לוחצים "הפוך תוכן לזמין", ואחר כך "רענן נגנים".
- **"לא הצלחתי ליצור נגן וידאו":** ב-Windows מהדורת N אין Windows Media Player. מתקינים אותו דרך "הגדרות ← אפליקציות ← תכונות אופציונליות ← Windows Media Player".
- **המסמך שמור ב-OneDrive:** צריך לשמור אותו בתיקייה רגילה במחשב.
- **הלשונית לא מופיעה, או שהכפתורים לא עושים כלום:** בדוק שביטלת את החסימה בקובץ (ראה "התקנה") ושהוא נמצא בתיקיית STARTUP.

## סרטון מ-YouTube

בשביל זה לא צריך את התוסף. ב-Word 2019 יש אפשרות מובנית: **הוספה ← וידאו מקוון**, ומדביקים את הקישור. הצפייה דורשת חיבור לאינטרנט.
